# 📦 컨테이너 물류 배송 웹시스템 - Cosmos

> 3D 시뮬레이션을 통해 물류 수출 시 적절한 컨테이너 공간 배정 및 적재 시각화를 제공하는 물류 최적화 웹 시스템

## 🔍 프로젝트 개요

팬데믹 이후 해상 물류 수요가 급증하면서, 수출 담당자는 컨테이너에 물류가 어느 정도 부피와 무게를 차지하는지 파악할 필요성이 커졌습니다.

**Cosmos**는 다음을 목표로 합니다:
- 물류 상품 정보를 기반으로 컨테이너 내 3D 적재 시뮬레이션 제공
- 수출 담당자의 업무 효율성 및 컨테이너 운영 효율 향상
- 부피/무게 기준 최적 컨테이너 추천 및 적재 시각화



## 🚀 주요 기능

### ✅ 공통 기능
- 사용자 회원가입 및 로그인
- 사용자 권한에 따른 기능 분리 (일반 사용자 / 수출 담당자)

### 👤 일반 사용자 기능
- 상품 등록 및 수정
- 등록된 상품 정보 조회 (수량, 무게, 출고 마감 시간 등)

### 📦 수출 담당자 기능
- 컨테이너 등록, 팔레트 등록 및 수정
- 상품과 컨테이너 연계
- 컨테이너 내 상품 적재 시뮬레이션 (3D 시각화)

### 🧩 시뮬레이션 기능
- `three.js`를 활용한 3D 가상 적재 공간 구현
- 팔레트 내 상품 적재 상태 시각화
- 다양한 컨테이너 유형(20FT, 40FT, 40FT HQ 등) 적용 가능



## 🛠 사용 기술

| 구성 | 기술 스택 |
|------|-----------|
| **Frontend** | React.js, Three.js |
| **Backend** | Spring Boot |
| **시각화** | Three.js 기반 3D 시뮬레이션 |
| **데이터베이스** | MySQL |
| **기타** | JSON 기반 API, RESTful 구조 등 |



## 📈 기대 효과 및 확장 방안

### ✅ 사용자 측면
- 간편한 상품 등록 및 시뮬레이션 → 업무 효율성 향상
- UI/UX 최적화 → 정보 파악과 작업 흐름 간소화

### ✅ 수출 담당자 측면
- 컨테이너 최적 활용 → 비용 절감 및 수익성 향상
- 시각화를 통한 오류 예방 및 운영 최적화

### 🔄 확장 방안
1. **3D Bin-Packing Problem 알고리즘 고도화**
   - 현재 수동 입력 기반 → 자동 최적화 알고리즘 적용 예정
2. **모바일 앱 개발**
   - 현장 실무자 접근성과 관리 편의성 향상
